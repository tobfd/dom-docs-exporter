<h1 align="center">DOM & Docs Exporter</h1>

<p align="center">
  Chrome extension that exports documentation pages as clean <b>Markdown</b> / text,<br>
  or a page's <b>cleaned HTML</b> – for one or many tabs at once. No DevTools console needed.
</p>

---

## Features

- **Docs export** – grabs the main content of a documentation page (skips navigation, sidebars, footers, hidden elements) as
  - **Markdown**: headings, code blocks with language, lists, tables, links, images – ideal for pasting into ChatGPT, Claude or Gemini
  - **Plain text**
- **DOM export** – cleaned HTML of the whole page. `script`, `style`, `svg`, `iframe` and `noscript` are always removed. Cleanup presets:
  - **For LLM** – smallest output: also strips `link`/`meta`, comments, `style` and `data-*` attributes, base64 data URLs and whitespace
  - **For selectors** – keeps `data-*` attributes (often the most stable selectors) and line breaks; for building extensions and scrapers
  - **Custom** – toggle every option yourself, each one explains when it's useful
- **Multiple tabs** – pick tabs from a checklist, then save one file per tab or combine them into a single file
- **Download or clipboard** – files land in `Downloads/dom-docs-exporter/` as `host_page-title_YYYY-MM-DD_HH-mm.md|txt|html`; clipboard mode shows a character and token estimate
- **Right-click menu** – *DOM & Docs Exporter → Docs/DOM → Clipboard/Download* for the current page
- **Optional source header** – title, URL and export date at the top of each file
- **English and German UI**, following the browser language; settings are remembered

## Install

**From a release**

1. Download `dom-docs-exporter-vX.Y.Z.zip` from the [Releases](../../releases) page and unzip it
2. Open `chrome://extensions` and enable **Developer mode**
3. Click **Load unpacked** and select the unzipped folder

**From source**

Clone or download this repository, then **Load unpacked** → select the `extension/` folder. After changing code, hit the reload button on the extension card.

> To export local `file://` pages, enable *Allow access to file URLs* on the extension's details page.
> Browser pages (`chrome://…`) and the Chrome Web Store can't be exported – Chrome blocks all extensions there.

## Permissions

| Permission | Why |
|---|---|
| `scripting` + host access to all sites | Read the content of the tabs you choose to export (only when you click export) |
| `tabs` | Show titles and URLs in the tab checklist |
| `favicon` | Show tab icons from Chrome's local favicon cache |
| `downloads` | Save exported files |
| `offscreen` | Turn exported text into a downloadable file |
| `clipboardWrite` | Copy exports to the clipboard |
| `contextMenus` | Right-click menu |
| `storage` | Remember your settings |

No data leaves your browser: there are no network requests, analytics or remote code.

## Development

Requires Node.js 22+ (only for the helper scripts – the extension itself has no build step or dependencies).

```sh
npm run check   # validate manifest, referenced files, icons, locales, JS syntax
npm run build   # check + pack extension/ into dist/dom-docs-exporter-v<version>.zip
npm run icons   # regenerate extension/icons/*.png
```

CI runs `npm run build` on every push and pull request. Pushing a tag like `v1.2.0` creates a GitHub release with the zip attached – bump `version` in both `extension/manifest.json` and `package.json` first (`npm run check` verifies they match).

```
extension/
  manifest.json
  background.js        service worker: context menu, runs exports
  lib/extract.js       injected into the page: DOM cleanup + HTML → Markdown
  lib/exporter.js      multi-tab export, file names, downloads
  lib/settings.js      defaults, DOM cleanup presets, chrome.storage
  lib/i18n.js          chrome.i18n helpers
  _locales/{en,de}/    UI strings
  offscreen/           creates blob URLs for downloads
  popup/               popup UI
  icons/               generated by scripts/generate-icons.mjs
scripts/               check, build, icon generator
```

To add a UI language, copy `extension/_locales/en/` to a new locale folder (e.g. `fr/`) and translate the `message` values.
